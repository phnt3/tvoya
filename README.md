# ТВОЯ: демо-сайт

Демо для предложения клиенту: мебель на заказ, Сыктывкар, Чкалова 28/1, ТЦ «Солнечный». Сделан на основе Scroll Kit, без библиотек. Чтобы посмотреть, откройте `index.html`.

## ⚠️ Сначала замените фото

Положите свои фото в `assets/` с именами `1`…`6` — расширение любое (`.jpg`, `.jpeg`, `.png`, `.webp`), сайт найдёт сам. Пока фото нет, показываются заглушки из `assets/demo/`:

| Файл | Ориентация | Где на сайте |
|---|---|---|
| `1.jpg` | вертикальное | лента работ |
| `2.jpg` | горизонтальное | **первый экран на весь экран**, лента работ |
| `3.jpg` | вертикальное | лента работ |
| `4.jpg` | горизонтальное | раскрытие «Реальные проекты», карточка «Гарантия» |
| `5.jpg` | горизонтальное | лента работ, карточка «10+ лет» |
| `6.jpg` | горизонтальное | лента работ, карточка «Своё производство» |

Номера идут в том порядке, в котором фото были загружены в папку «2»: от самого нового к самому старому. Если хотите другое фото на первом экране, переименуйте его в `2.jpg`.

**Размер:** перед загрузкой уменьшите каждое фото до 1920–2000 px по длинной стороне, качество JPG 75–80% (squoosh.app). Должно получиться 200–400 КБ на фото. Оригиналы по 1,5 МБ будут долго грузиться с телефона.

## Структура

1. **Hero.** Фото на весь экран, «Мебель для твоего дома», кнопки «Рассчитать стоимость» и «Написать в VK».
2. **3D-комната «от идеи до готовой мебели».** Комната в CSS 3D, четыре шага по скроллу:
   1. Замер: появляются стены и красные размерные линии.
   2. 3D-проект: кухня и шкаф-купе возникают красным каркасом, как в программе проектирования.
   3. Производство: каркас заполняется материалами (белый, графит, дерево, зеркало).
   4. Установка: двери-купе разъезжаются, ящики выдвигаются, появляется красный пуф.

   Камера облетает комнату и реагирует на мышь.
3. **Манифест** по словам: «делаем мебель под квартиру».
4. **Красная бегущая строка:** замер, 3D-проект, производство, установка.
5. **Что делаем:** 7 направлений. На компьютере строка заливается красным при наведении. Клик отмечает пункт в форме и прокручивает к ней.
6. **«Реальные проекты».** Фото раскрывается на весь экран, дальше горизонтальная лента работ.
7. **«Примерно → Точно».** Экран раскрывается красным кругом: фиксированная смета.
8. **Почему мы, стопкой:** 10+ лет, своё производство, гарантийное сопровождение.
9. **Контакты:** телефон, VK, адрес, карта, форма с выбором типа мебели и полем «размеры или идея».

Палитра: светлый тёплый серый, графит и красный `#df052a` из их логотипа. Меняется в `:root` файла `tvoya.css`.
